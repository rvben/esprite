# Reproducing the screenshots

These are product documentation captures of running applications. No UI or
framebuffer pixels are painted over, and no private material is blurred into a
shareable screenshot. The content is neutral before capture.

## Included control demo

```sh
make build
python3 examples/html-studio/server.py --runner ./build/esprite --target cyd_tft
```

Open the printed loopback URL. In **Touch the display**, enter X **80**, Y **100**
and choose **Tap**. The LED control turns blue. Capture the page viewport without
browser chrome; save it as `docs/images/html-studio.png`.

## External Paperplane application

The second image comes from Paperplane's own repository and is not generated by
the Esprite build. In that checkout, build the simulator and start its isolated
offline demo with `./build-simulator.sh` and `./run-demo.sh`. The Today page must
say **Demo forecast** and the studio must say **Offline demo · synthetic weather**.
The demo uses a fixed synthetic forecast and temporary storage. Capture the page
viewport as `docs/images/paperplane.png`.

Review both rendered images before replacing the documentation assets. Exclude
browser tabs, address bars, usernames, local paths, network names, device IDs,
coordinates, real forecasts, voice recordings and personal photographs. PNG
files should contain only image data, without textual or location metadata.
